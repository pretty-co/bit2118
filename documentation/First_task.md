
# Task : NumPy Arrays and Numerical Computation

## 1. Mathematical Concept
NumPy arrays store numerical values and allow efficient mathematical operations.

## 2. Original Application
A weather station records 24 hourly temperatures.

## 3. Inputs
24 temperature readings in degrees Celsius.

## 4. Mathematical Operations
- Mean
- Minimum
- Maximum
- Celsius-to-Fahrenheit conversion

## 5. Parameter Modification
One temperature reading was changed from 29.4°C to 35.0°C.

The average and maximum temperatures increased, while the minimum remained unchanged.

## 6. Output Interpretation
The mean represents the average temperature. The minimum and maximum represent the lowest and highest recorded temperatures.

## 7. Modified Real-World Application
Vaccine transportation temperature monitoring.

## 8. Assumptions
The acceptable vaccine transportation temperature is assumed to be between 2°C and 8°C.

## 9. Input Data
[4.2, 4.5, 5.0, 4.8, 5.3, 6.1, 8.5, 5.2]

## 10. Output Interpretation
The average temperature is 5.45°C. One reading of 8.5°C exceeds the assumed maximum temperature.

## 11. Conclusion
NumPy makes it possible to calculate statistical values and identify unusual readings efficiently.
